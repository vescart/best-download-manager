# best-download-manager

Public website for **Best Download Manager**, a Chrome extension: product page and privacy policy.
Served by GitHub Pages at https://vescart.github.io/best-download-manager/

- `index.html` — product page
- `privacy.html` — privacy policy (linked from the Chrome Web Store listing and the extension)
- `support.html` — FAQ and contact (the store listing's Support URL)

The extension's source code is kept in a separate private repository.
