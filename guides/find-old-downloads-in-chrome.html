How to find old downloads in Chrome

Updated 17 October 2026 · 4 min read

You downloaded something days or weeks ago and now you can't find it. Chrome keeps a record of what you download, so in most cases the file is easy to track down. Here's how, from the quickest method to the fallback.

1. Open Chrome's Downloads page

Any of these opens the full list of what you've downloaded:

  • Windows and Linux: press Ctrl + J
  • Mac: press ⌘ + Shift + J
  • Any computer: type chrome://downloads in the address bar and press Enter
  • Or open Chrome's menu (⋮, top right) and choose Downloads

The list is sorted with the newest downloads first and grouped by date.

2. Search the list

Use the search box at the top of the Downloads page. It matches the file name and the web address the file came from, so searching for a site's name (for example bank or drive) often finds a file even when you don't remember what it was called.

3. Open the file's folder

Under each download, click Show in folder (on Mac, Show in Finder). Your file manager opens with the file selected. This is the fastest way to move, rename or attach it.

4. If it says “Deleted” or the link does nothing

Chrome remembers downloads even after the file itself is gone. An entry marked Deleted means the file was moved, renamed or removed after downloading. Try:

  • Your computer's search (Spotlight on Mac, the Start menu search on Windows) for the file name.
  • The Trash or Recycle Bin.
  • Downloading it again from the original site — the Downloads page shows the source link under each entry.

5. If the download isn't in the list at all

  • Downloads in Incognito windows aren't kept in the list after you close the window, but the files are still saved on your computer.
  • Cleared history: if you or a cleaner app cleared download history, the record is gone (the file usually isn't). Look in your Downloads folder.
  • Different folder: check where Chrome saves files in Settings → Downloads → Location.
  • Different Chrome profile: each profile has its own download list.

Find files by date in your Downloads folder

On Mac, open Finder → Downloads, choose list view and sort by Date Added. On Windows, open File Explorer → Downloads and sort by Date modified. Recent downloads rise to the top.
