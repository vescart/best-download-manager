How to clear Chrome download history without deleting files

Updated 17 October 2026 · 3 min read

Good news first: clearing Chrome's download history never deletes the files on your computer. It only removes the record from Chrome's list. Here are the safe ways to tidy it up.

Remove a single download from the list

  1. Open the Downloads page: Ctrl + J on Windows, ⌘ + Shift + J on Mac, or go to chrome://downloads.
  2. Find the entry and click the ✕ (Remove from list) next to it.

The entry disappears; the file stays where it is.

Clear the whole list

  1. Open chrome://downloads.
  2. Click the menu (⋮) on the Downloads page and choose Clear all.

Again, only the list is cleared — your files are untouched.

Clear it together with other browsing data

Chrome's Delete browsing data panel (Settings → Privacy and security) has a Download history option. It also removes only the list. Make sure you don't tick things you want to keep, like passwords or cookies.

What if I actually want to delete the file?

Click Show in folder under the download, then delete the file in Finder or File Explorer. That way you can see exactly what you're removing — and it goes to the Trash or Recycle Bin, so you can undo it.

Why keep the history at all?

The list is a handy record: it shows where each file came from and lets you re-download it. If the list is simply too long to use, a visual manager with search and filters helps more than wiping it.
